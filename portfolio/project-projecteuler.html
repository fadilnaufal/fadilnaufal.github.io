Project Overview

This portfolio features a curated collection of programming solutions to the complex, mathematics-driven challenges of Project Euler. These cases demonstrate my ability to bridge advanced mathematical theories with efficient computational algorithms. Each solved problem highlights a methodical approach to algorithmic design, performance optimization, and logical problem-solving, showcasing not just the ability to write functional code, but the skill to engineer highly performant solutions for computationally heavy tasks. Ultimately, this collection reflects my dedication to analytical rigor, precision, and continuous technical growth in software development.

Here is an interesting example of a problem regarding Collatz conjecture (Problem 14).

To solve this problem, I developed a Python solution that calculates the Collatz sequence length for every starting number under the specified or customized limit (one million or less for time-saving visual). The core logic is implemented using basic Python control structures, including for loops to iterate through the starting numbers, while loops and if-else statements to apply the Collatz rules (n/2 for even and 3n+1 for odd), and standard list structures to track the sequences. After identifying the lengths, I selected two starting numbers and mapped out their respective Collatz sequences visually by plotting them using matplotlib.

The solution to Problem 14 and other solved problems is available in the repository.
