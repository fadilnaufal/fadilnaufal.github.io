Project Overview

This is a 3D Computer Aided Design (CAD) design based on TooTallToby https://tootalltoby.com/ CAD Speedmodeling Competition. The core objective of the competition is to replicate a 3D object from a provided Detailed Engineering Drawing (DED) as quickly and accurately as possible which is determined by calculating the correct final mass within a strict tolerance based on the model's volume and material density.

The specific design modeled here is the Toy Ball for Structure, drawing no. 25-SPO-15. This is a Tier 4 Complexity model.

I designed it using OpenSCAD, a code-based parametric CAD program.

To determine the volume, the OpenSCAD model was exported as .STL file(s) which was opened in FreeCAD to mesh, and ran through the Python console with the function FreeCAD.ActiveDocument.ActiveObject.Shape.Volume to get the volume(s). After getting the volume, the mass(s) is calculated in a spreadsheet.

The completed model achieved a total mass of 63.34197 grams, representing an error margin of 0.0284 %. This is an excellent result, falling well within the allowable tolerance.
